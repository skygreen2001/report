# 2026-10-17 企业报表平台

## 数据源配置：暴露「数据库域名 + 端口」，默认 localhost:3306

**需求**：数据源配置还要能填数据库域名和端口号，默认 localhost 和 3306。

**背景**：`data_source` 表早就有 `host`/`port` 两列，`dsForm` 状态里也有
（`host:'127.0.0.1', port:3306`），但**表单 UI 只有名称/库名/用户名/密码四项**，
host/port 等于写死不可见 —— 用户根本改不了。

**改动**（`d/page.tsx`，仅开发者数据源 tab）：
- `dsForm` 默认值改为 `host:'localhost'`、`port:'3306'`（**port 由 number 改为 string**，
  这样输入框可清空重填；后端 `CreateDsSchema` 要求 `port` 为正整数，故在 `createDs`
  提交时转换：`const payload = { ...dsForm, port: Number(dsForm.port) || 3306 }`）。
- 表单在「名称」后新增两个输入框：数据库域名（`maxWidth:150`）、端口（`type="number"`、`maxWidth:90`），
  均带 `title` 提示默认值。
- 数据源列表行补显 `· {d.host}:{d.port}`，便于核对配置是否生效。

**验证**：tsc 0、网关 20/20、`/platform/d` 200；
API 实测 建 host=localhost/3306 与 host=127.0.0.1/3307 均落库正确，
重复（同 host/端口/库名/账号）→ 409 `DATA_SOURCE_DUPLICATE`。测试数据已清理。

`env -u NODE_OPTIONS .../node node_modules/next/dist/bin/next dev -p 3111` 重启（run_in_background）。
