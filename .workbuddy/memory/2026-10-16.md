# 2026-10-16 企业报表平台

## 开发者页折叠化：模型配置内联 + 新建报表折叠

**需求链**：
1. 开发者「模型配置」不再单独占左侧菜单，内联进「报表」和「需求收件箱」。
2. 开发者「新建报表」模块也做成折叠。

**实现**（`d/page.tsx`，仅开发者页，甲方页不动）：
- 抽出 `llmBody`（模型列表+添加表单，含 `datalist#llm-models`）与 `llmInline`（折叠卡片）两个 JSX 片段，
  定义在 `if (!boot) return …` 之后、主 `return` 之前。
- 左侧菜单删除「模型配置」node（现：数据源/数据库结构文档/需求收件箱/报表/应用管理/回收站）。
- `报表` tab 顶部渲染 `{llmInline}`；`需求收件箱` tab 改为 `<>…</>` 包 `{llmInline}` + 需求卡片（避免卡片套卡片）。
- 保留 `tab === 'llm'` 整页块，`?tab=llm` 深链仍可直达全页模型配置。
- 新增 `llmOpen` / `newReportOpen` 两个折叠状态，均**默认 false（收起）**；
  标题栏 `onClick` 切换，右侧 badge 显示「展开/收起」。
- 「新建报表（直接写 SQL）」卡片：`<strong>` 改为可点 `.row` 标题栏，表单体（名称/数据源/SQL
  textarea/参数/预览/保存）用 `{newReportOpen && (<>…</>)}` 包裹，卡片本身仍闭合在最外层。

**验证**：tsc 0、网关 20/20、`/platform/d` 200。
`llmInline` 定义 585、引用 695(报表)/860(需求)；新建报表折叠结构 698~780。

**约定**：开发者页这类「低频但占地方」的模块统一做成默认折叠，主内容（列表）优先可见。
